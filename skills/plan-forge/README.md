# plan-forge

Three skills for going from idea to handoff without losing decisions on the way.

| Skill | Trigger | Output |
|-------|---------|--------|
| spec | "spec this out", /spec | Decision-complete spec under 600 words |
| breakdown | "break this down", /breakdown | Ordered tasks with dependencies and a verify step each |
| plan-review | "review this plan", /plan-review | Ranked findings and a ready/not-ready verdict |

Designed to be cheap on tokens: short bodies, one reference file loaded only when a spec is written, and hand-offs to your existing dispatch-authoring, dispatch-as-file, pulse-before-plan, stop-and-ask, and completion-report skills instead of restating them.

No connectors, agents, or hooks.
